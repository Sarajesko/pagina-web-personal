# Favicon — PG

**Decisión:** en pestaña solo **PG** (círculo blanco + rojo).  
`<PG/>` completo es ilegible a 16px → se usa en el **header**, no en el favicon.

| Archivo | Uso |
|---------|-----|
| `favicon.svg` | Preferido |
| `favicon.ico` | Fallback |
| `favicon-16.png` / `favicon-32.png` | PNG |
| `apple-touch-icon.png` | 180×180 |
